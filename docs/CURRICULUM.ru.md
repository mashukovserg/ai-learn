# Учебная программа AI: путь для начинающих

## Путь: Основы AI
**Цель:** Понять экосистему, геополитику и базовые механизмы современных LLM.

### Модуль 1: Современный ландшафт AI
- [x] **Комната 101: Ландшафт LLM** — 13 заданий
  - *Темы:* Original Gangster (OpenAI), Лидерборды (ELO/Chatbot Arena), Геополитика (США vs Китай vs ЕС), Суверенный AI, рамка выбора модели, зрелость SDK-интеграции.
- [x] **Комната 102: Как мыслят LLM** — 14 заданий (включая сортировку, категоризацию, таймлайн, ментора, сценарий)
  - *Темы:* Токены и BPE, предсказание следующего токена (логиты → Softmax → авторегрессивный цикл), Self-Attention с Q/K/V и multi-head, позиционное кодирование (синусоидальное → RoPE), температура и стратегии декодинга (greedy, beam search, top-k, top-p/nucleus, штраф за повторы), контекстное окно (рост, KV-кэш, «Lost in the Middle»), галлюцинации.
- [x] **Комната 103: Основы промптинга** — 5 заданий
  - *Темы:* Системные промпты, Few-shot/Zero-shot, Борьба с галлюцинациями, Итерация промптов.
- [x] **AI Career Trajectories (`ai-career-trajectories`)** — 10 заданий (включая sorting, categorize, mentor, scenario, input); 4 главы с источниками вокруг интерактивной карты карьеры
  - *Темы:* IC-, research- и management-траектории, точки развилки после senior-уровня, фокус навыков по этапам и реалистичный первый план перехода в AI.

  - *Темы:* Основы RAG, качество поиска, цитирование источников и калибровка доверия.

### Модуль 3: Архитектура и адаптация

### Модуль 5: Практика

  - *Темы:* Наборы оценки, метрики, release gates для LLM-фич.

  - *Темы:* Промпты, композиция, негативные промпты, управление seed, коммерческое использование.
- [x] **Литературный обзор в эпоху ИИ (Literature Review in the AI Era)** — 10 заданий (включая sorting, categorize, scenario, mentor)
  - *Темы:* Строгий ИИ-обзор литературы; постановка вопроса по PICO и декомпозиция на подзапросы; критерии включения/исключения до поиска; дедупликация и двухпроходный скрининг в стиле PRISMA; проверка ссылок против галлюцинированных/несуществующих цитат (разрешить DOI → подтвердить издание/авторов/цитату); синтез, таблицы доказательств и воспроизводимый журнал аудита. ### Модуль 6: Открытые модели

  - *Темы:* Открытые веса vs open source, компромиссы приватность/офлайн/затраты, ландшафт моделей (Llama, Qwen, Mistral, Gemma, Phi, DeepSeek), первый запуск через Ollama/LM Studio, основы квантизации и VRAM, пределы и гибридная стратегия «локально + облако».
- [x] **Llama 3.1 8B (открытая модель)** — 7 заданий (включая categorize, scenario, mentor)
  - *Темы:* Углублённый разбор одной модели: GQA, RoPE-масштабирование, контекст 128K, Llama Community License, запуск через Ollama/vLLM/Transformers, бюджеты VRAM.
- [x] **Локальный RAG: приватный поиск по своим документам** — 11 заданий (включая sorting, categorize, mentor, scenario)
  - *Темы:* Конкретная задача для локальных моделей: приватный смысловой поиск по своему архиву; фазы индексации и запроса (чанкинг → эмбеддинги → векторная база → поиск → генерация); выбор многоязычных эмбеддингов (multilingual-e5/bge-m3 против англоязычной MiniLM, MTEB); правило одной модели и переиндексация; отладка «сначала ретрив»; источники как механизм доверия; честные границы «локально vs облако».

## Путь: Идеи и споры об ИИ
**Цель:** Понять основные концептуальные дебаты в AI-сообществах и трансформировать их в практические продуктовые решения.

- [x] **ChatGPT moment** — 6 заданий
  - *Темы:* Психология интерфейса и массовая адаптация, вирусные петли дистрибуции, экономика поиска в режиме "Code Red", продуктовые и governance-импликации.
- [x] **Гипотеза масштабирования** — 5 заданий
  - *Темы:* Три столпа (вычисления/данные/параметры), Эмерджентные способности, Оптимальность по Chinchilla.
- [x] **Сингулярность в AI-дебатах** — 6 заданий
  - *Темы:* Аргументы за/против, структура сравнения лагерей, фрейминг рисков, операционные импликации для команд.
- [x] **История AI** — 4 задания (включая таймлайн)
  - *Темы:* Таймлайн AI, ключевые вехи, ключевые голоса в дискуссии о рисках ИИ, от подраздела Computer Science до глобального явления.
- [x] **Сингулярность в AI-дебатах** — 6 заданий
- [x] **Пост-ChatGPT эпоха (Post-ChatGPT Era)** — 6 заданий
  - *Темы:* Компромиссы API-доступа, динамика экосистем open-weight, модели рассуждений (o1), геополитика вычислений.

## Примечания о доступности
- Все комнаты обслуживаются динамическим маршрутом `src/app/[lang]/rooms/[id]/page.tsx`. Теоретический контент находится в `src/components/theory/`.
- Прогресс сохраняется через API бэкенда при авторизации, с fallback на localStorage для гостей (хук `useProgress`).
- На 2026-03-24 обновлён UI-базис под режим чтения: уточнены типографические стеки, для длинных теоретических блоков добавлен `reading-prose`, ритм отступов на уровне оболочки унифицирован через `content-shell`.
